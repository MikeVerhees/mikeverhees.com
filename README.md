# MikeVerhees.com

My personal website built with [Next.js](https://nextjs.org/) and [Tailwind CSS](https://tailwindcss.com/), statically exported and deployed to GitHub Pages.

## Development

Run `npm run dev` to start the development server.

## Build

Run `npm run build` to produce a static export in `out/`. Run `npm run preview` to serve that output locally.
