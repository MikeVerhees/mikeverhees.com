This post is a **draft**, so it only shows up when running `npm run dev`.

To publish a new post:

1. Copy this file in `src/content/blog/` and give it a name such as `my-first-post.md`. That name becomes the URL: `/blog/my-first-post/`.
2. Update the title, date and tags at the top.
3. Remove `draft: true` (or set it to `false`).
